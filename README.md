<H1>Fish Freshness Classification via 2D Haar Discrete Wavelet Transform on LAB-Segmented Texture Images</H1>
A non-destructive computer vision system that classifies fish freshness in real-time by analyzing external skin texture using LAB color space segmentation and 2D Haar wavelet transform features across multiple species under variable lighting conditions.
